# ✨ Faretasmic!

Faretasmic is a flight fare price surveillance and predictive oracle engine rewritten as a modern React + TypeScript application on Vite.

## Features

- **High-Density Telemetry Tray**: Live API quota tracking (e.g., 412/1000 calls), Fail-Safe Fetch Shield status, and database synchronization indicators.
- **Predictive Oracle Engine**:
  - Live Buy/Hold recommendations with percentage variance vs. baseline span.
  - Historical Price Gauge with dynamic spectrum needle (Low / Typical / High).
  - Outbound & Return price anchors with multi-currency support (USD / CAD).
- **Price Trajectory Visualization**:
  - Dual format charting: Bar Graph 📊 and Line Graph 📈 with SVG stroke + scatter points.
  - Multi-date milestone markers and anchor indicator cards.
- **Flight Search Router**:
  - Direct deep-link routing cards to monitored carriers (North America, Asia, Europe).
  - Integrated Google Flights aggregator launch card.
- **Itinerary Management**:
  - Add Route modal with IATA airport autocomplete, junk fare filtering, passenger count, cabin class, date span calculations, pre/post buffer vectors, and carrier tagging.
  - Untrack verification and CSV data export for tracked trajectory datasets.
- **9 Curated Themes**:
  - Cozy Village, Cyberpunk, Gothic Crimson, Minimalist Light, Modern Dark, Modern Light, Retro Arcade, Synthwave Sunset, and Wasteland Terminal, with a Random theme selector.
- **Celestial Toast Engine**:
  - Animated notification popups with living aura and magic collapse transitions.

## Tech Stack

- React 18
- TypeScript
